# Lotérica da Avenida

Site da lotérica: https://lotoavenida.com.br

- Os bolões abertos vêm sozinhos do `dados.json` do Loterias 24 Horas (https://loterias24horas.com.br/dados.json).
- O prêmio da Mega-Sena vem das APIs públicas; se elas atrasarem, vale o `MANUAL` do script (concurso e valor).
- A contagem usa o cronograma da Mega (`CRON` no script).
